### 1.2 Anti-Duplikat: Aturan Distribusi Konten

Agar tidak terlihat spam, terapkan **aturan distribusi** ini:

1. **Satu ide utama = satu versi per akun, bukan tiga versi sama.**
   - Contoh: ide = "Si Sempurna & tekanan orang tua".
   - `.id`: Carousel tentang nilai 95 tapi tetap dimarahi karena "belum 100" (referensi PKL/akademik Indonesia).
   - `.global`: Carousel tentang perfectionism sebagai cognitive distortion (referensi CBT + hustle culture).
   - `@riung`: Carousel bilingual — üst (EN) tentang perfectionism pattern, alt (ID) tentang tekanan keluarga.

2. **Tidak boleh posting sama dalam 2 jam di 3 akun** — beri jarak 3–4 jam antar akun untuk algoritma.

3. **Konten viral (Reels/TikTok) hanya diproduksi 1x**, lalu di-*repackage*:
   - Video master 9:16 (20–30 detik) dibuat di `riung_ad_generator.html` / Canva / CapCut.
   - `.id`: Tambahkan teks overlay dalam Bahasa Indonesia, musik lo-fi lokal, CTA Play Store Indonesia.
   - `.global`: Subtitle Inggris lengkap, musik instrumental, CTA App Store / global Play Store.
   - `@riung`: Post video master + caption bilingual, lalu Story yang mengarahkan ke akun `.id` atau `.global` sesuai preferensi pengguna.

4. **Tidak pernah copy-paste caption sama** — selalu adaptasi nada.

## 3. ALUR OTOMASI CAMPAIGN (AUTOMATION WORKFLOW)

Dari perspektif `@automation-governance-architect`: sistem harus **pemerintahan (governance) dulu, baru otomatisasi** — tidak boleh menjalankan otomasi tanpa kontrol, audit, dan fallback manual.

### 3.1 Prinsip Otomasi (Governance)

1. **One Source of Truth (SSOT):** Semua ide konten utama disimpan dalam satu file master (contoh: `campaign/ide_master.md` atau Airtable / Notion) — bukan tersebar di ChatGPT, Excel, atau memo WhatsApp.
2. **Versi Kontrol:** Setiap aset (gambar, video, caption) memiliki versi (v1, v2, v3) dan status (draft → review → approved → published → archived).
3. **Human-in-the-Loop:** Otomasi hanya untuk **distribusi dan penjadwalan**, bukan untuk pembuatan konten tanpa review. Orang (content editor) harus menyetujui setiap versi `.id`, `.global`, dan `@riung` sebelum terbit.
4. **Audit Trail:** Setiap posting tersimpan dengan timestamp, akun, format, dan hasil (reach, engagement, konversi store click).
5. **Fallback:** Jika sistem gagal, ada cara manual dalam 30 menit (jadwal posting di spreadsheet + link aset di folder `campaign/approved/`).

### 3.2 Alur Otomasi: 1 Ide → 3 Versi → Posting Terjadwal

```
[IDE MASTER]  →  [GENERATE ASSET]  →  [ADAPT 3 AKUN]  →  [REVIEW MANUAL]  →  [SCHEDULE / AUTO-POST]  →  [ANALYTICS & FEEDBACK]
```

**Langkah detail:**

| No | Langkah | Alat / Tool | Output | Waktu | Catatan Governance |
|---|---|---|---|---|---|
| 1 | **Tulis ide master** | Notion / Airtable / `campaign/ide_master.md` | Ide + monster + hook + CTA + format | Senin pagi | 1 ide per minggu per akun = 3 ide/minggu total |
| 2 | **Generate aset visual** | Canva / Figma / `design/riung.pen` / `riung_ad_generator.html` | Master asset (carousel PNG / video MP4 9:16) | Senin–Selasa | Gunakan asset monster dari `design/aset3d_cut/` atau `assets/monsters/3d/` |
| 3 | **Adaptasi 3 versi** | Copy-paste ke template (lihat bagian 3.3) | File: `[ide]_id.md`, `[ide]_global.md`, `[ide]_hub.md` + gambar/video yang sudah diedit teks | Rabu | **Tidak boleh copy sama** — adaptasi nada, bahasa, CTA |
| 4 | **Review manual** | Content editor + psikolog (review clique) | Approved / Revisi | Kamis | Checklist: hook <3 detik? Nama monster muncul? CTA jelas? Tidak memaksa? (lihat `rencana-sosmed-3-akun.html` checklist) |
| 5 | **Jadwal posting** | Meta Business Suite / Buffer / Later / n8n / Zapier | Jadwal: `.id` Senin 19:00, `.global` Senin 08:00 UTC, `@riung` Senin 12:00 WIB (atau sesuaikan) | Kamis | Jeda 3–4 jam antar akun |
